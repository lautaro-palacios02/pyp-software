# Migración futura de dominio

No realizar estos cambios hasta disponer del dominio definitivo. Entonces: configurar DNS y Custom Domain en Render, reemplazar canonical/sitemap/robots/Open Graph y `legalConfig`, agregar la propiedad nueva en Search Console y Google Business, actualizar enlaces y aplicar redirecciones 301 permanentes del dominio antiguo al nuevo. Mantener el dominio anterior activo mientras Google procesa la migración.
